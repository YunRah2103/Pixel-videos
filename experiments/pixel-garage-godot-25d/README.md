# Pixel Garage 2.5D — isolated experiment

A real Godot 4.4 2.5D scene: original hand-directed pixel sprites placed in a genuine 3D world with a curved gravel mesh, physical depth relationships, and a perspective camera. This is not the earlier fully-3D pixelation approach or Python perspective simulation.

Generate native-resolution sprites with `python3 scripts/generate_art.py`. Run `bash render/render.sh` with Godot 4.4.1, Xvfb, Python/Pillow/numpy and FFmpeg. Outputs a 14-second 1080x1920 30 fps TikTok MP4, original audio and 5 screenshots. Source is separate from all prior Pixel Garage productions. No merge approval granted.
