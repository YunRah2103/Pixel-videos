# AFTERLIGHT — Cinder District (art revision)

An entirely original, code-authored 480 × 270 cyberpunk rooftop cinematic.

**Design correction:** The original proof had empty block-shaped buildings, a flat foreground, little architectural character, and too much dependence on its moon and moving figure. This revision introduces a substantially rebuilt multi-plane setting: layered skyline architecture, fictional neon signage, lantern-lit ramen interior, visible rooftops, trussed water tower, exposed pipes, power lines, fire escapes, a detailed street canyon, animated commuter train, and a handmade running/jumping sprite.

## Local render

```bash
python3 -m pip install -r requirements-demo.txt
python3 scripts/afterlight.py --seconds 8 --out out/afterlight.mp4 \\
  --poster out/afterlight.png --layers out/afterlight-layers
```

Requires FFmpeg. Outputs a crisp 1920×1080 H.264 MP4 via 4× nearest-neighbour upscale, a full-res PNG poster and separately editable original-resolution transparent PNG layer images. Each of the 192 source frames is drawn directly at 480 × 270 by deterministic Python/Pillow primitives. No AI stills, rasterized hi-res footage, pixelation post filter, Gaussian blur, bloom or purchased game assets are used. Build uses existing Pixel-videos' Pillow and FFmpeg methodology without replacing SunsetHarbor.

All original art is in [scripts/afterlight.py](../scripts/afterlight.py). The per-layer PNGs are regenerated by the script and can be edited in Pixelorama/Aseprite or any raster editor.

## Creative review

This is an architectural improvement and a working motion proof, not a claim of studio-grade hand-painted quality. To reach a professional Katana ZERO-like craft level, the next art pass should prioritise silhouette redesign and hand-edited building surfaces before adding lighting effects or more movement.
